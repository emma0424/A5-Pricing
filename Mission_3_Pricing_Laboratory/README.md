# Mission 3 — Pricing & Cost Laboratory

Interactive cost and pricing model for the Outfit Hanger concept. The live page is published at `/Mission_3_Pricing_Laboratory/` in the A5-Pricing GitHub Pages site. Mission 2 remains at the site root.

## Run and build

The reproducible project source is in `source/`.

```sh
pnpm install
pnpm dev
pnpm build
```

The deployed static files at this folder's root are generated from `source/` with Vite and use relative asset paths for the GitHub Pages subdirectory.

## Model notes

Prices and source checks are dated October 27, 2026. DTC checkout, costs, product specifications, and monthly sales volume are unconfirmed. Illustrative and estimated expenses are editable and marked in the interface. User settings remain in local browser storage. DOCX and JSON decision reports require a current evaluation and explicit student confirmation in the interface.
